# 검증 기록

검증일: 2026-10-25 (한국시간)

## 실제 수집

- 공식 5개 목록과 각 상세 페이지, robots.txt, 이용약관 확인.
- 전체 수집 성공: 93개 목록 페이지, 정책/상세 포함 106회 요청, 1,458개 분류별 항목, 고유 설교 1,370편.
- 공개 목록의 날짜 범위: 2013-12-15 ~ 2026-10-23.
- 증분 재실행 성공: 17회 요청, 160개 목록 항목 확인, 추가 0·변경 0. 최초 순환 cursor는 최신 페이지와 겹칠 수 있으며 이후 과거 페이지로 이동.
- 정규화 실패 13개 분류 항목(고유 설교 12편): 본문 미기재, 원본 오타, 부분 절 표기. 원문을 유지하며 비교에서는 제외. 일반적으로 쓰는 아가서 명칭은 아가의 별칭으로 지원.
- 웹 도구는 일부 URL에서 타임아웃이 있었지만 로컬 Python requests로 공식 HTTPS 응답을 확인하고 수집 성공. 인증서 검증을 해제하지 않음.

## 자동 테스트

- Python unittest: 28개 통과.
- Node 검색 엔진: 8개 통과. 모든 실제 본문과 엣지 케이스의 Python/JavaScript 결과 일치.
- 50,000개 가상 데이터의 검색 검사 통과. 로컬 필터 실행 약 5~15ms (인덱스 구축 시간 별도, 장치별 성능 차이 있음).
- Chromium / WebKit 각각 1440px, 390px, 320px: 78개 브라우저 검사 통과.
- 검색·성경/장/구약신약·날짜/예배 유형·정렬·빈 결과·본문 비교·CSV 다운로드·페이지 이동·5분 갱신·잘못된 배포 JSON 거부·가로 넘침 없음 확인.
- 모바일 장 입력 후 첫 비교 클릭 누락을 발견하고 중복 change/input 리렌더를 제거한 후 재검증.
- CSV의 UTF-8 BOM, CRLF, 따옴표/쉼표 이스케이프, 수식 시작 문자 무력화와 브라우저 다운로드 바이트 확인.
- 실제 전체 JSON 스키마/식별자/내용 해시/정규화 재검증 성공.

- actionlint 1.7.12로 timezone을 포함한 Actions 워크플로 정적 검사 통과.

## 외부 환경 검증 범위

- Excel 데스크톱 앱에서 직접 열기, 실제 iOS/Android 기기의 터치 동작은 미검증. BOM/CSV 바이트와 Chromium·WebKit 반응형 동작으로 검증함.
- 미래 예약 시각 09:10의 실제 자동 실행 여부는 해당 시각 이후 Actions 실행 이력으로 확인해야 함. GitHub 예약 실행은 지연될 수 있음.
- 공식 목록 밖의 삭제/비공개 과거 설교는 수집하지 않음.
- GitHub Pages Source=GitHub Actions, Actions 기본 토큰 쓰기 권한, 활성 예약 워크플로 확인.
- [수집 없는 검증 데이터 배포 실행](https://github.com/ssung123-del/oryun-sermon-archive/actions/runs/40137544005): update/deploy 성공.
- [최종 배포 실행](https://github.com/ssung123-del/oryun-sermon-archive/actions/runs/40137709076): 성공.
- 공개 사이트 index와 sermons.json HTTP 200, 공개 JSON 전체 Python 검증 성공. 1,458개 출처 항목 / 고유 설교 1,370편.
- 최종 공개 index.html·sermons.json이 로컬 검증본과 바이트 단위로 일치.
- 공개 URL을 Chromium 데스크톱·WebKit 모바일로 재확인: 1,370편 표시, 요 8:1-11 + 요한복음 8장 검색 3편, 본문 비교 창 정상, JavaScript 오류 없음.
- **미해결:** GitHub 기본 runner의 공식 사이트 수집은 TCP 연결 시간 초과로 실패. Linux x64·Linux ARM·macOS 모두 DNS는 정상, robots.txt의 443 연결 실패. [진단 기록](https://github.com/ssung123-del/oryun-sermon-archive/actions/runs/40137547170). 서버/네트워크 차단 여부는 확정할 수 없음. 예약은 등록했으나 완전 자동 수집이 정상 운영된다고 보고하지 않음.
- 위 실제 수집 실패 시 기존 JSON이 변경되지 않고 deploy가 생략되는 것까지 확인. 프록시·대체 도메인·TLS 해제 등 우회는 사용하지 않음.
